雞爸爸一家｜房間內容整合更新 13

接續鼠窩更新 12。請保留原本資料夾結構，將本包內的檔案上傳到 GitHub 儲存庫根目錄，同名檔案覆蓋。不要只把 ZIP 上傳到網站，也不要多包一層資料夾。

這包包含
1. 每個房間背景正下方一條橫排 BAR，依「影片 → 文章 → 小遊戲 → 其他」排列。沒有內容的分類略過；手機可左右滑動，不壓縮成很小的字。
2. 點房間物品、遊戲卡片或 BAR，可在同頁下方玩對應遊戲。切換時結束上一個遊戲，只載入目前選擇的內容。
3. 客廳掃貓毛、神明拼圖；餐廳喝水、餵貓、水果英文、找零食；兔窩、鼠窩和遊戲間現有遊戲均整合到各頁下方。原本已經在頁面的澆花、腳踏車、餐桌禮儀、行事曆、生活流程、猜弟弟需求、咖啡和浴室任務保留。
4. 餐廳背景與 BAR 下方的第一區，直接展開「雞爸爸一家的菜單」，再往下才是遊戲。阿嬤優格收入菜單，介紹內有原本優格故事的站內文章連結；點阿嬤也跳到這個菜單項目。
5. 各房間大標題：
   客廳：來坐，一起看我們家的影片。
   餐廳：一起來用餐吧
   鼠窩：親子生活教養
   兔窩：安靜穩定力量
   雞窩：生活點滴記錄
   遊戲間：一起放鬆一下
   廚房：自己來做料理
   浴室：浴廁安全守則
6. 人物調整參考身高：雞爸爸175、鼠媽媽160、兔阿嬤150、鼠姊姊120、龍弟弟90公分。前方略大、後方略小；坐姿另行考量。餐廳縮小後方雞爸爸與兔阿嬤、調整前方鼠媽媽；客廳放大最前方雞爸爸，降低孩子相對於成人的大小；其他房間同步調整。
7. 貼圖小舖與認識我們保留原本歡迎文字，補回插畫卡片與小人物迎賓，右方不再只有孤立人物。
