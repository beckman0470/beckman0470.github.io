BABYMONSTER Game Room - v13 Child-First Player

Install: Upload babymonster-classroom.html to the ROOT of your GitHub Pages repository, replacing the existing file. Keep /assets/babymonster/*.gif unchanged. This ZIP has NO wrapper folder.

What works:
- Three oversized playback controls: previous song, play/pause, next song.
- Direct, authorized YouTube embeds for DRIP, SHEESH, FOREVER, BATTER UP.
- Official YouTube captions requested through the embedded player (availability varies).
- Minimal lyrics teaching demonstration for one authentic opening DRIP line only, using a very short excerpt and introductory timing estimate.
- No parent configuration, no typing, no browser TTS. Design stays cream/sage/wood.

Known limitations / NOT finished:
- Seven actual independent cartoon teaching audio tracks NOT created. This update deliberately removes the adult browser TTS rather than pretending otherwise.
- Four songs' whole lyric libraries and frame-perfect line/member synchronization NOT included. Official video captions are YouTube-controlled and not guaranteed.
- Some browsers block YouTube embeds or ads; use Brave to view the website for Shields filtering where supported.
- Teaching is only demonstrative for DRIP's first line; no claims of complete curriculum.
- Artwork sourced from existing /assets/babymonster/*.gif path, uploaded in previous versions.

No copied music or full copyrighted lyrics are redistributed.
