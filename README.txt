手機遊戲操作與兔阿嬤養生數位佛堂更新包

更新內容
1. 手機或窄／低螢幕開啟遊戲時，底部操作列在遊戲畫面可見時出現，提供開始／重新開始／發球／投下一球／鎖定方向與力度、暫停或繼續，以及返回設定。直接操作既有遊戲按鈕，不建立另一份遊戲狀態。按鈕同步原來的可用狀態。
2. 打磚塊、雷電飛機、節奏畫面依可見高度縮放，保留長寬比；觸控按鍵位於底部操作列上方，預留iPhone底部安全區。棒球與投籃場景和量表也縮小留出操作空間。
3. 兔阿嬤影音小客廳改名「兔阿嬤的養生數位佛堂」，包含外層入口、內頁標題、返回連結及語音名稱。
4. 數位佛堂使用本包的獨立插畫，不依賴YouTube灰色預設縮圖。另換三張遊戲封面：接龍牌桌近景、窗邊數獨、活潑堆方塊。四張圖片分別生成，構圖及表情不同。

上傳方式
解壓後把根目錄HTML與play、assets資料夾合併到現有GitHub網站根目錄，覆蓋同名檔案，不刪除其他檔案。特別注意assets/adult-games四張webp也要一起上傳；只上傳HTML／JS仍然會缺圖。此為增量包，沿用已上傳的原站遊戲與影片清單，不是整站備份。沒有包含index.html。
本包尚未直接部署官網，需等待最新Pages deploy成功後查看。網址相同，樣式與腳本版本已更新。

檢查
已檢查腳本語法、三個遊戲入口載入操作列、四張圖片實體及映射、養生數位佛堂相關名稱。
以390×720的瀏覽器手機寬度模擬操作：打磚塊發球與暫停、飛機開始與暫停、節奏開始與暫停、投籃鎖方向及鎖力度、棒球投下一球及打擊。也確認飛機開始後底部主按鈕更新為重新開始，四張新封面載入與佛堂入口連結正確。這是瀏覽器尺寸模擬，並非實體iPhone測試。
原遊戲規則、存檔與原影片播放限制沿用。此次未製作舊式國民健康操影片。
