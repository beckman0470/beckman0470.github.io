1. 將本 ZIP 解壓後的 babymonster-ep01.html 及 assets/ 依原有相對路徑覆蓋上傳。

4. dr​ip-timestamps.json 提供 55 句的 line start/end，可供日後 LyricTimestamps JSON 逐字時間碼替換。
5. 未修改已定案粉紅舞台及成員造型。
6. 此包包含使用者提供的孩童錄音，公開 GitHub 上傳將公開該音檔。
