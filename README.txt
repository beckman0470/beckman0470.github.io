雞爸爸大人放風：四個分類與遊戲封面更新包

更新內容
1. 大人放風分成兔阿嬤、鼠媽媽、雞爸爸、雞爸爸一家四個分類。
2. 24款遊戲入口與3個家庭角落都有對應封面；另提供3張角色分類插畫，共30張圖片。
3. 經典遊戲歸回角色：兔阿嬤有俄羅斯方塊、接龍、數獨；鼠媽媽有四川省麻將、打磚塊與英文排字。
4. 雞爸爸新增四款原創遊戲：節奏舞台、奇幻戰斧冒險、星空雷翼、一家大富翁。
5. 雞爸爸一家收進內心小惡魔、珍山陳經典語錄、雞爸爸家；點卡片才打開互動內容。
6. 手機分類兩欄、遊戲卡片一欄，完整顯示正方形封面。舊主題進入遊戲後會收起圖片列表。

上傳方式
把解壓後的 relax.html、relax-family.html、dad-arcade.html，以及 assets、css、play 裡的檔案，上傳到現有 GitHub 網站根目錄，保留資料夾結構，覆蓋同名檔案。不要刪除網站其他檔案。
這是增量更新包，沿用原網站既有遊戲與共用檔案；沒有包含整個網站，也沒有取代首頁 index.html。
檔案不應放在另一層同名資料夾。請以 README 同一層的三個 HTML 為網站根目錄。
GitHub Pages 部署成功後開啟 /relax.html 查看。遊戲請從網站開啟，iPhone 的檔案快速預覽可能不執行 JavaScript。

音樂說明
節奏遊戲有 BABYMONSTER 官方 YouTube 的 CLIK CLAK、FOREVER 選項。預覽環境回報影片無法嵌入；實際是否可播依 YouTube 和地區條件而定，未保證官方歌曲能在網站內播放。
可以改用原創節奏練習，或選擇「使用裝置上的音樂」載入自己可使用的音樂檔。檔案只在裝置播放，不上傳到伺服器。譜面是自動編排的60秒練習譜，不是原曲逐音採譜。
音樂載入後按開始遊戲，再按播放器播放；判定校正可調整 -500～500ms。
