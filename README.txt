BABYMONSTER DRIP EP01 逐句暫停版（粉紅舞台版型不變）

上傳 babymonster-ep01.html、assets/bm-approved/drip-stage.jpg、assets/dodo/dodo-song.m4a 到 GitHub Pages 根目錄相同路徑。

1. 點「鼠姊姊演唱」，播放錄音，聽到該句開始按 ①、結束按 ②，之後即能自動在句尾暫停。
2. 點「播放這一句並教學」，唱完會唸中文翻譯、逐字英文發音與中文解釋、最後複習。
3. 要連續數句，請在「家長設定」新增並輸入下一句歌詞與中文，分別標記開始／結束，再按「已校準句子連續教學」。
4. 時間標記只儲存在目前瀏覽器的 localStorage，不會傳到伺服器。歌詞未逐句校時，切勿視為已完成全曲同步。
5. 錄音被公開放在 GitHub Pages 時，所有網站訪客可能存取。
