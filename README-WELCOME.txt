房間迎賓互動更新

接續目前網站與剛剛的神明拼圖更新使用。解壓後，把檔案依原本相對路徑覆蓋到儲存庫根目錄，請保留 css、js、assets、play 的資料夾層級。README 不必上傳。等待 GitHub Pages 部署完成後重新整理。

更新內容：
・人物縮小約 12%，迎賓縮為一句，減少遮擋。
・互動物品改為淺色細描邊，取消強光與放大。
・鼠窩用背景書櫃與床；兔窩用佛像經書與扶手椅；遊戲間用背景街機、積木、畫桌與桌遊櫃。
・大人留在固定位置，錯開揮手、眨眼與伸懶腰。小朋友偶爾搖晃、蹲下與輕跳；書房貓咪偶爾短距離移動。
・點人物顯示對話，也使用裝置提供的中文語音打招呼；不自動播放聲音。
・點客廳沙發讓雞爸爸坐下；點鼠窩床鋪讓鼠姊姊躺下閉眼。
・點兔窩震動機讓兔阿嬤站上去抖動；點遊戲間跳跳馬讓弟弟坐上去彈跳。再次點擊可停止；點人物可回原位。
・保留暫停動作、減少動態效果設定與鍵盤操作。
