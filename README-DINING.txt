餐廳一家人日常更新 11

請接續 10 版客廳更新使用。解壓後依原本相對路徑覆蓋儲存庫根目錄，保留 assets、css、js、play 等資料夾層級；README 不必上傳。等待 GitHub Pages 部署成功後重新整理。本包尚未上傳或部署。

本次更新：
・移除額外蓋在餐廳下方的大型橢圓餐桌和餐盤 ICON。
・雅虎喝水與右右吃飼料，點擊直達既有添水／餵貓遊戲。
・荳荳挑水果，連到全水果題庫的英文猜字／排字，共 14 個水果。
・龍弟弟找零食，新增階梯冒險：慢慢玩模式看方向跳，節奏模式另挑戰時機；十二階收集四份點心，有暫停、重新開始與鍵盤操作。
・雞爸爸和兔阿嬤坐在原背景餐桌後方面向鏡頭，分別吃藍莓與優格。
・點雞爸爸進餐桌禮儀；點優格進〈阿格！阿格！兔阿嬤不會拉肚子的優格〉。
・鼠媽媽端菜，點菜盤開拿手料理菜單。
・七道料理都有獨立圖片、食材份量和作法：義大利麵、白飯、番茄蛋花湯、蛤蠣湯、滷肉、肉片包番茄、寶寶粥。
・餐廳下方整理四個遊戲入口與料理菜單；圖底部保留一行小字入口。

檢查：
修改的 JavaScript 語法通過。添水三次與餵食五口可完成。水果猜出 APPLE、排出 BANANA 成功。階梯十二階可過關、收集四份點心，暫停可續玩，三次錯方向會結束回合。雞爸爸和優格、菜單入口皆可操作，七道食譜可展開。手機 320 寬度無橫向溢出，開始和跳躍按鈕可按；水果字母、料理菜單也可操作。
